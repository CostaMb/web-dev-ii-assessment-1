## My Implementation

For Task 2 of my Web Development II Assessment 1, I created a responsive movie streaming website called watch.it using HTML and CSS.

I followed the supplied wireframes and used the provided movie images, descriptions and brand colours.

I used CSS Grid and Flexbox to organise the movie cards and media queries to adjust the layout for different screen sizes.

On mobile, the movies appear in a single column. On tablets, they appear in two columns. On desktop, the first movie takes up the full width, followed by smaller movie cards arranged according to the wireframe.

I also used the Teko and Lato fonts from Google Fonts and followed the spacing requirements provided in the specification.

## Testing

I tested the website using Safari Responsive Design Mode on my MacBook.

I checked the layout at 360px, 440px, 768px, 1024px and 1280px to see how the movie cards, images, navigation and spacing adapted to different screen sizes.
